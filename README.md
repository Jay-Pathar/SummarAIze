## ✨ Description
`SummarAIze` is an AI-powered Chrome extension designed to quickly summarize articles and web pages. Leveraging the Gemini API, it provides users with various summary options including brief, detailed, or bullet-point formats, helping them grasp key information efficiently.

## 🚀 Features
*   **Multiple Summary Types:** Choose between brief, detailed, or bullet-point summaries.
*   **AI-Powered Summarization:** Utilizes the Gemini API for advanced and accurate content summarization.
*   **Copy to Clipboard:** Easily copy the generated summary to your clipboard.
*   **API Key Management:** Securely store and manage your Gemini API key in the extension's options.

## 🛠️ Technologies Used

## 📥 Installation
1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/Jay-Pathar/SummarAIze.git
    cd SummarAIze
    ```
2.  **Load in Chrome:**
    *   Open Chrome and go to `chrome://extensions`.
    *   Enable "Developer mode" by toggling the switch in the top right corner.
    *   Click on "Load unpacked" and select the `SummarAIze` directory.
3.  **Set up Gemini API Key:**
    *   After installation, the extension will automatically open the options page.
    *   Enter your Gemini API key in the provided field and save it. (You can get an API key from [Google AI Studio](https://ai.google.dev/)).

## 💡 Usage
1.  **Navigate to an Article:** Go to any web page containing an article you wish to summarize.
2.  **Open the Extension:** Click on the SummarAIze extension icon in your Chrome toolbar.
3.  **Select Summary Type:** Choose your preferred summary format (Brief, Detailed, or Bullet Points) from the dropdown menu.
4.  **Summarize:** Click the "Summarize This Page" button. The summary will appear in the extension popup.
5.  **Copy Summary:** Click the "Copy Summary" button to copy the generated text to your clipboard.
